## 第三轮：用户实测截图指出三处问题（尺寸/裁切、对话呈现、字体布局）
用户反馈：① 设备选择框尺寸不对、按钮没显示全；② 主窗口与原型差距大，"需要严格做和原型图一样的展示，比如字体、格式布局、对话模式的呈现"。

### 根因与修复（runner/gui_steps.py）
1. **设备选择框按钮被裁**：`geometry("560x330")` 硬编码 + 暗色主题下 Treeview 行高变 30 → 内容溢出。改为 `_fit_geometry()` 按 `winfo_reqwidth/reqheight()` 自适应（树 height 8→5），刷新后重新贴合；状态行改 tk.Label 以便上色（失败红/正常灰）。
2. **右栏 Spinbox/保存按钮被裁**：根因是主窗口 `resizable(False, False)` + 列宽不足。改 `resizable(True, True)` + `minsize(1180,720)`；preview 容器 `columnconfigure(minsize=EXPECT_IMG_W)`；等待时间从横排（标签+Spinbox 挤一行）改为**竖排两列 + 独立"保存等待时间"按钮**。
3. **AI 对话从纯文本改为气泡**：新增 `_ChatPane` 类（Canvas + 内嵌 Frame + 消息 Label），AI 左灰底 `#2b303b`、用户右紫底 `#4a3f7d`、系统提示居中浅色，带 1px 描边。`_ai_chat_append` 三种角色分发（AI/用户/系统）。候选信息+三按钮合并为 `_ai_cand_frame` 卡片，显隐走 `_show_cand_card()/_set_cand_btns()`（pack before=input_row）。AI Tab 内部从 grid 改 **pack**。
4. **字体整体放大一号**：UI 10→11、Caption/List 9→10、MONO 9→10。
5. **左栏新增工具条**：网格显隐、－/＋ 缩放（带百分比标签）、1:1、⟳刷新；新增 `_toggle_grid/_zoom/_zoom_reset/_render_canvas`。缩放复用 `self.scale`（点击换算 `event.x / self.scale` 依旧准确）。

### 关键教训（已写入 SKILL.md 6.5/6.6）
- 新建开发工具：`runner/_ui_preview.py`（离屏预览器，绕过设备闸门渲染真实窗口出 PNG），必须用系统 Python `D:/Python/Python311/python.exe`（托管 3.13.12 无 tkinter）。
- **ImageGrab 抓不到 Tk 子控件像素**（canvas 内嵌帧/ttk 主题控件在截图里是空白）。截图"某块空白"≠控件没渲染，别据此改布局；用 `winfo_*` 几何日志或 `canvas.postscript()` 验证。踩过两次误判。
- Tk 布局陷阱：grid 行权重 + 父容器 sticky="n" 会把容器算成 1×1（内容看似消失）；固定 geometry 会裁切按钮；PhotoImage 重新赋值时旧引用被 GC 会闪黑（需 `_photo_ref` 保活 + 先 create_image 再赋值）。
- 后台跑脚本：日志写工作区内路径（Windows Python 的 /tmp ≠ Git Bash /tmp，之前日志丢失）；结束用 taskkill 收尾。
